Basic Network

Build a basic LAN using Cisco Packet Tracer.

🎯 Objective

  • Understand basic LAN topology.
  • Connect PCs to a Cisco switch.
  • Configure IPv4 addresses.
  • Test connectivity using ping.

🌐 Topology

PC1 → Switch → PC2


Network: 192.168.10.0/24

💻 IP Configuration

PC1
IP Address: 192.168.10.10
Subnet Mask: 255.255.255.0

PC2
IP Address: 192.168.10.20
Subnet Mask: 255.255.255.0

🧪 Test Connectivity

PC1> ping 192.168.10.20

Successful replies indicate that the two PCs can communicate through the switch.
